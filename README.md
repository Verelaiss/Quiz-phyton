# Quiz em Python

## Objetivo

Este projeto foi criado com o objetivo de praticar Python e me familiarizar com a linguagem e com o VS Code.

Durante o desenvolvimento, também pratiquei conceitos básicos de programação, uso do terminal, organização de código e versionamento com Git e GitHub.

A ideia principal foi entender o fluxo completo de um projeto simples: escrever o código, testar, corrigir problemas, versionar e publicar no GitHub.
