# Quiz em Python

## Objetivo

Este projeto foi criado com o objetivo de praticar Python e me familiarizar com a linguagem e com o VS Code.

Durante o desenvolvimento, também pratiquei conceitos básicos de programação, uso do terminal, organização de código e versionamento com Git e GitHub.

A ideia principal foi entender o fluxo completo de um projeto simples: escrever o código, testar, corrigir problemas, versionar e publicar no GitHub.


## Como funciona

O programa possui 10 perguntas pré-definidas de múltipla escolha, apresentadas uma por vez ao usuário.

Cada acerto vale 1 ponto e respostas incorretas não pontuam.

As respostas aceitas são A, B, C ou D. Caso o usuário digite um caractere diferente dessas opções, o programa exibe uma mensagem de erro e solicita uma nova resposta.

O programa informa se a resposta está correta ou incorreta e, ao final, mostra a pontuação total obtida.
